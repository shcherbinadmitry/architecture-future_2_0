# Технический радар «Будущее 2.0»

## Введение

Технический радар компании «Будущее 2.0» отражает текущее состояние технологического ландшафта и планируемые изменения в рамках трансформации IT-инфраструктуры.

Радар помогает командам принимать обоснованные решения о выборе технологий, понимать стратегическое направление развития и планировать миграцию с устаревших систем на современные решения.

## Квадранты

- **Языки и Фреймворки** - языки программирования, фреймворки и библиотеки, используемые для разработки сервисов и интерфейсов
- **Практики и Паттерны** - архитектурные подходы, методологии разработки и управления данными
- **Платформы** - облачные платформы, базы данных, хранилища данных и инфраструктурные решения
- **Инструменты** - конкретные инструменты для разработки, интеграции, аналитики и мониторинга

## Кольца

- **Активно используем (Adopt)** - технологии, рекомендованные к использованию в новых проектах. Проверены и доказали свою эффективность.
- **Пробуем (Trial)** - технологии, которые проходят пилотное внедрение. Рекомендуется использовать в ограниченном объёме для оценки.
- **Изучаем (Assess)** - технологии, которые мы исследуем и оцениваем. Пока не рекомендуются для продакшн-использования.
- **Выкидываем (Hold)** - устаревшие технологии, от которых планируется отказ. Не рекомендуются для новых проектов.

## Контекст
Компания «Будущее 2.0» переходит от монолитной архитектуры (DWH на SQL Server 2008) к доменной архитектуре на основе Data Mesh с Data Lakehouse для аналитики. Ключевые цели:

1. Создание портала самообслуживания (витрина данных)
2. Независимое развитие бизнес-направлений (финтех, ИИ, клиники)
3. Интеграция новых партнёров (фармацевтика, оборудование)
4. Миграция в облако
5. Обеспечение безопасности и compliance
