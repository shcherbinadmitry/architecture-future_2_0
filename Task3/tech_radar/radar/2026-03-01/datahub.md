## DataHub (LinkedIn)

**Статус:** Активно внедряем

**Назначение:** Data Catalog - каталог данных для поиска, документирования и управления метаданными. Ключевой компонент портала самообслуживания.

**Использование:**
- **Аналитический домен** - каталог всех Data Products
- **Все домены** - документирование схем данных и API
- **Data Governance** - линейность данных (data lineage), политики доступа
- **Портал самообслуживания** - поиск данных для бизнес-пользователей

**Бизнес-сценарии:**
- **Self-service аналитика** - бизнес-пользователи находят нужные данные самостоятельно
- **Data Governance** - контроль качества и линейности данных
- **Compliance** - аудит использования данных, соответствие регуляторам
- **Онбординг** - новые сотрудники быстро находят нужные данные

**Влияние на бизнес:**
- Время поиска данных: дни → минуты
- Снижение нагрузки на IT-отдел (80%+ запросов через self-service)
- Прозрачность использования данных для compliance
