## PowerBuilder

**Статус:** Выводим из эксплуатации

**Текущее использование:** Клиентский интерфейс для операторов клиник. Используется для регистрации пациентов, управления расписанием, работы с медицинскими данными.

**Проблемы:**
- Технология **90-х годов** - крайне ограниченное сообщество
- Невозможность создания **современного UX** (мобильный доступ, адаптивность)
- **Сложность найма** разработчиков PowerBuilder
- Отсутствие интеграции с современными API и облачными сервисами
- Высокая стоимость лицензий и поддержки

**Затронутые бизнес-сценарии:**
- Работа операторов клиник (устаревший интерфейс)
- Онлайн-запись пациентов (невозможна)
- Мобильный доступ для врачей (невозможен)

**Замена:** React/Vue.js - современный веб-интерфейс с адаптивным дизайном, мобильной версией и интеграцией через REST API.
