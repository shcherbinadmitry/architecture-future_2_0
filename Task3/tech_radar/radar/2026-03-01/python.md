## Python

**Статус:** Активно используем

**Текущее использование:** ИИ-сервисы для работы с медицинскими данными (анализ снимков, предиктивная аналитика, поддержка врачебных решений).

**Расширение использования:**
- **ИИ домен** - ML-модели (TensorFlow/PyTorch), MLflow, FastAPI
- **Медицинский домен** - API для работы с медицинскими данными (FastAPI)
- **Аналитический домен** - ETL-скрипты, data quality проверки
- **Data Engineering** - Apache Spark (PySpark), dbt

**Бизнес-сценарии:**
- ИИ-анализ медицинских снимков - поддержка врачебных решений
- Предиктивная аналитика - прогнозирование заболеваний
- API для медицинских данных - контролируемый доступ к чувствительным данным
- ETL-процессы - подготовка Data Products для аналитики

**Преимущества:**
- Богатая экосистема для ML/AI (TensorFlow, PyTorch, scikit-learn)
- FastAPI - высокопроизводительный фреймворк для API
- Большое сообщество, легко нанимать специалистов
- Интеграция с Apache Spark (PySpark)
