## Apache Spark

**Статус:** Пробуем

**Назначение:** Распределённый движок обработки данных. Используется для масштабной обработки и трансформации данных в Data Lakehouse.

**Использование:**
- **Аналитический домен** - обработка больших объёмов данных в Lakehouse
- **ИИ домен** - подготовка данных для обучения ML-моделей (PySpark)
- **ETL** - масштабные трансформации данных

**Бизнес-сценарии:**
- **Обработка больших данных** - сотни терабайт за минуты
- **Подготовка данных для ИИ** - обработка медицинских данных для ML
- **Масштабирование** - горизонтальное масштабирование обработки

**Влияние на бизнес:**
- Обработка данных, которая раньше занимала часы, выполняется за минуты
- Возможность работы с неструктурированными данными (снимки, тексты)
