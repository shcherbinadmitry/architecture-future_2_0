## Terraform

**Статус:** Активно внедряем

**Назначение:** Infrastructure as Code (IaC) - описание и управление облачной инфраструктурой через код. Обеспечивает воспроизводимость и версионирование инфраструктуры.

**Использование:**
- **Все домены** - развёртывание инфраструктуры (БД, Kubernetes, сети)
- **Облачная миграция** - автоматизация создания облачных ресурсов
- **Среды** - идентичные dev/staging/prod среды

**Бизнес-сценарии:**
- **Быстрое развёртывание** - инфраструктура для нового домена за часы
- **Воспроизводимость** - идентичные среды для тестирования
- **Масштабирование** - быстрое добавление ресурсов
- **Disaster Recovery** - восстановление инфраструктуры из кода

**Влияние на бизнес:**
- Время развёртывания нового домена: недели → часы
- Снижение ошибок при ручной настройке
- Быстрое восстановление после аварий (RTO < 1 час)
