## Apache Airflow

**Статус:** Активно внедряем

**Назначение:** Платформа оркестрации ETL/ELT процессов. Управляет потоками данных между доменами и Data Lakehouse.

**Использование:**
- **Аналитический домен** - оркестрация загрузки Data Products в Lakehouse
- **Все домены** - запуск ETL-задач по расписанию
- **Data Quality** - запуск проверок качества данных
- **Мониторинг** - отслеживание выполнения пайплайнов

**Бизнес-сценарии:**
- **Актуальность данных** - автоматическая загрузка данных по расписанию
- **Надёжность ETL** - retry, алерты, мониторинг выполнения
- **Прозрачность** - визуализация DAG, история выполнения

**Влияние на бизнес:**
- Автоматизация рутинных задач по загрузке данных
- Снижение ошибок при ручном управлении ETL
- Прозрачность для Data Engineering команды
