## PostgreSQL

**Статус:** Активно внедряем (замена SQL Server 2008 для операционных БД)

**Назначение:** Операционная база данных для каждого домена. Заменяет единый SQL Server 2008 для хранения операционных данных.

**Использование в доменах:**
- **Клинический** - профили пациентов, расписание, данные клиник
- **Медицинских данных** - структурированные медицинские данные
- **Финтех** - счета, транзакции, кредиты (ACID критичен)
- **Операционный** - HR, инвентаризация, закупки
- **Партнёрский** - каталоги партнёров, конфигураций

**Бизнес-сценарии:**
- **Изоляция доменов** - каждый домен имеет свою БД
- **Производительность** - оптимизация под конкретный тип нагрузки
- **Масштабирование** - независимое масштабирование каждой БД
- **Снижение затрат** - open source, нет лицензионных платежей

**Преимущества перед SQL Server 2008:**
- Open source - $0 лицензий (экономия ~$15,000/ядро/год)
- Активная разработка и поддержка сообщества
- Богатая экосистема расширений (PostGIS, TimescaleDB, pgvector)
- Отличная поддержка JSON, полнотекстового поиска
- Большой рынок специалистов
