## Java / Spring Boot

**Статус:** Активно используем

**Текущее использование:** Финтех-сервисы - бизнес-логика финансовых операций, кредитование.

**Расширение использования:**
- **Финтех домен** - сложная бизнес-логика (кредиты, страховки)
- **Операционный домен** - HR, инвентаризация, закупки
- **Партнёрский домен** - интеграционные адаптеры

**Бизнес-сценарии:**
- Кредитование пациентов - сложная бизнес-логика с транзакциями
- Управление персоналом (HR) - корпоративные процессы
- Управление закупками - интеграция с поставщиками

**Преимущества:**
- Зрелая экосистема для enterprise-разработки
- Spring Boot - быстрый старт микросервисов
- Отличная поддержка транзакций и безопасности
- Большое сообщество и рынок специалистов
