## Power BI

**Статус:** Оцениваем замену

**Текущее использование:** BI-система с большим количеством кастомизаций поверх DWH. Используется для отчётности и дашбордов.

**Проблемы:**
- Тесная привязка к **SQL Server** и экосистеме Microsoft
- Большое количество **кастомизаций**, которые сложно поддерживать
- Ограниченные возможности **self-service** для бизнес-пользователей
- Зависимость от лицензий Microsoft

**Что хорошо:**
- Знакомый инструмент для текущих пользователей
- Хорошая интеграция с Excel

**Затронутые бизнес-сценарии:**
- ️ Управленческая отчётность (работает, но медленно)
- ️ Дашборды KPI (ограниченный self-service)

**Решение:** Оцениваем переход на Tableau/Looker для лучшей интеграции с Data Lakehouse и расширенных возможностей self-service. Возможно сохранение Power BI как одного из инструментов BI-платформы.
