## React

**Статус:** Внедряем (замена PowerBuilder)

**Назначение:** Современный фреймворк для создания пользовательских интерфейсов. Используется для трёх ключевых порталов: Клинического портала (замена PowerBuilder), Финансового портала и Портала самообслуживания.

**Использование в доменах:**
- **Клинический домен** — **Клинический портал**: единый интерфейс для врачей (расписание, медкарты, ИИ-анализ) и операторов (регистрация пациентов, запись на приём, очереди). Полная замена PowerBuilder
- **Финтех домен** — **Финансовый портал**: интерфейс для финансовых специалистов (управление счетами, обработка платежей, кредитование, биллинг)
- **Аналитический домен** — **Портал самообслуживания**: витрина данных, конструктор отчётов для бизнес-аналитиков и менеджеров

**Бизнес-сценарии:**
- **Клинический портал** — работа врачей и операторов клиник через современный веб-интерфейс
- **Финансовый портал** — обработка платежей, кредитование, биллинг для финансовых специалистов
- **Портал самообслуживания** — конструктор отчётов для аналитиков и менеджеров
- Онлайн-запись пациентов — веб-приложение для пациентов
- Мобильный доступ для врачей — адаптивный дизайн

**Преимущества:**
- Компонентный подход - переиспользование UI-элементов
- Огромная экосистема библиотек
- Большой рынок специалистов
- Поддержка мобильных устройств (React Native)
