## Data Lakehouse (Databricks / Snowflake)

**Статус:** Активно внедряем

**Назначение:** Единое аналитическое хранилище, объединяющее преимущества Data Lake (гибкость, масштабируемость) и Data Warehouse (ACID транзакции, SQL). Заменяет DWH на SQL Server 2008 для аналитических задач.

**Использование:**
- **Аналитический домен** - центральное хранилище для всех Data Products
- **BI-платформа** - источник данных для дашбордов и отчётов
- **Портал самообслуживания** - данные для self-service аналитики
- **Data Science** - данные для ML-экспериментов

**Бизнес-сценарии:**
- **Быстрая отчётность** - отчёты за минуты вместо часов (columnar storage, кэширование)
- **Self-service аналитика** - бизнес-пользователи строят отчёты самостоятельно
- **Масштабирование** - независимое масштабирование compute и storage
- **Консолидированная аналитика** - данные из всех доменов в одном месте

**Преимущества перед SQL Server 2008 DWH:**
- Columnar storage - в 10-100x быстрее для аналитических запросов
- Масштабирование compute и storage независимо
- Поддержка структурированных и неструктурированных данных
- ACID транзакции (Delta Lake / Iceberg)
- Time travel - версионирование данных
- Стоимость хранения в 5-10x ниже

**Влияние на бизнес:**
- Время формирования отчётов: часы → минуты (95%+ улучшение)
- Стоимость хранения: снижение в 5-10x
- Количество self-service отчётов: 0% → 80%+
