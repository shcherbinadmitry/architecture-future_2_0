## Kong API Gateway

**Статус:** Активно внедряем

**Назначение:** API Gateway - единая точка входа для всех API. Обеспечивает аутентификацию, авторизацию, rate limiting, маршрутизацию и мониторинг.

**Использование:**
- **Все домены** - маршрутизация запросов к доменным API
- **Партнёрский домен** - управление доступом внешних партнёров
- **Безопасность** - аутентификация (OAuth2/JWT), авторизация (RBAC)
- **Мониторинг** - логирование и метрики всех API-вызовов

**Бизнес-сценарии:**
- **Безопасность** - централизованная аутентификация и авторизация
- **Интеграция партнёров** - управление доступом фармацевтики и оборудования
- **Мониторинг** - отслеживание использования API
- **Rate limiting** - защита от перегрузки

**Влияние на бизнес:**
- Единая точка управления доступом (compliance)
- Быстрое подключение новых партнёров (конфигурация, а не разработка)
- Защита от DDoS и перегрузки
