## Microsoft SQL Server 2008

**Статус:** Выводим из эксплуатации

**Текущее использование:** Центральное хранилище данных (DWH), содержащее все данные компании - медицинские, финансовые, операционные. Объём - сотни терабайт.

**Проблемы:**
- Версия 2008 года - **отсутствие поддержки** от Microsoft с 2019 года
- Критические **уязвимости безопасности** без патчей
- **Низкая производительность** аналитики - отчёты формируются часами
- **Единая точка отказа** - при сбое останавливается весь бизнес
- Сложность найма специалистов по устаревшей версии
- Высокая стоимость лицензий Enterprise Edition

**Затронутые бизнес-сценарии:**
- Построение отчётности (часы вместо минут)
- Интеграция новых бизнесов (требует изменений в DWH)
- Масштабирование (только вертикальное)

**План миграции:** Поэтапная миграция данных в доменные БД (PostgreSQL) и Data Lakehouse (Databricks/Snowflake) в течение 12 месяцев.
