## GitOps / CI/CD

**Статус:** Активно внедряем

**Назначение:** Практика управления инфраструктурой и деплоем через Git. Все изменения проходят через pull request, code review и автоматический деплой.

**Применение:**
- **Все домены** - автоматический деплой сервисов
- **Инфраструктура** - Terraform через GitOps
- **Data Engineering** - деплой dbt-моделей и Airflow DAG

**Бизнес-сценарии:**
- **Быстрый деплой** - новые версии за минуты, а не дни
- **Качество** - автоматические тесты перед деплоем
- **Откат** - быстрый откат при проблемах
- **Аудит** - полная история изменений в Git

**Влияние на бизнес:**
- Ускорение Time-to-Market (деплой за минуты)
- Снижение рисков при обновлениях (автотесты, откат)
- Прозрачность изменений для compliance
