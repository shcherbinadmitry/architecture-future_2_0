## Облачная платформа (AWS / Azure / GCP)

**Статус:** Активно внедряем

**Назначение:** Облачная инфраструктура для размещения всех доменов, хранилищ данных и сервисов. Замена on-premise оборудования.

**Использование:**
- **Все домены** - размещение сервисов и баз данных
- **Data Lakehouse** - управляемые сервисы (Databricks/Snowflake)
- **Kubernetes** - управляемый кластер (EKS/AKS/GKE)
- **ИИ домен** - GPU-инстансы для обучения моделей
- **Disaster Recovery** - geo-распределение для отказоустойчивости

**Бизнес-сценарии:**
- **Масштабирование** - ресурсы за минуты, а не месяцы (закупка оборудования)
- **Отказоустойчивость** - geo-распределение, автоматическое восстановление
- **Снижение затрат** - OPEX вместо CAPEX, оплата по потреблению
- **Быстрый старт** - новый домен разворачивается за часы

**Влияние на бизнес:**
- Снижение TCO (OPEX vs CAPEX)
- Время развёртывания: месяцы → часы
- Доступность: 99.9%+ с geo-распределением
- Гибкость: масштабирование под сезонные нагрузки
