## Drawio

**Статус:** Активно используем

**Назначение:** Инструменты для создания архитектурных диаграмм, DFD, C4 и других визуализаций.

**Использование:**
- **Drawio** - детальные архитектурные диаграммы
- **Mermaid** - диаграммы в Markdown (GitHub, документация)
- **PlantUML** - C4 диаграммы, UML

**Бизнес-сценарии:**
- **Документация** - визуализация архитектуры для всех команд
- **Коммуникация** - понятные диаграммы для бизнеса и разработки
- **Версионирование** - диаграммы в Git вместе с кодом
