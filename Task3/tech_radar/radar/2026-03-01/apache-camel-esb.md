## Apache Camel (ESB)

**Статус:** Выводим из эксплуатации

**Текущее использование:** Сервисная шина предприятия (ESB) - центральный интеграционный компонент. Через ESB проходят все потоки данных: медицинские, финансовые, операционные.

**Проблемы:**
- **Единая точка отказа** - при сбое ESB останавливается весь обмен данными
- **Узкое место** при росте нагрузки - все данные проходят через одну шину
- Сложная конфигурация маршрутов
- Синхронная модель - блокирующие вызовы снижают производительность
- Сложность масштабирования

**Затронутые бизнес-сценарии:**
- Обмен медицинскими данными (риск остановки)
- Финансовые транзакции (риск потери данных)
- Интеграция с ИИ-сервисами (медленная передача)

**Замена:** Apache Kafka (асинхронный event streaming) + API Gateway (Kong/Apigee) для синхронных вызовов. Распределённая архитектура без единой точки отказа.
