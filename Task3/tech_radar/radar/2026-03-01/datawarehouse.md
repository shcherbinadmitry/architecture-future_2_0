## Централизованный DWH (монолитный подход)

**Статус:** Отказываемся от монолитного подхода

**Текущее использование:** Единое централизованное хранилище данных на SQL Server 2008, содержащее все данные компании и значительную часть бизнес-логики.

**Проблемы монолитного DWH:**
- Все данные в одном месте - **единая точка отказа**
- Бизнес-логика в хранимых процедурах - **сложность изменений**
- Конкуренция OLTP и OLAP за ресурсы - **низкая производительность**
- Невозможность независимого масштабирования доменов

**Замена:** Data Mesh + Data Lakehouse
- Операционные данные → доменные БД (PostgreSQL)
- Аналитические данные → Data Lakehouse (Databricks/Snowflake)
- Бизнес-логика → микросервисы доменов
- Трансформации → dbt + Airflow

**Бизнес-сценарии:**
- Монолитный DWH блокирует все ключевые цели бизнеса
- Data Mesh + Lakehouse решают проблемы производительности, масштабируемости и независимости
