## Redis

**Статус:** Пробуем

**Назначение:** In-memory хранилище для кэширования. Используется для ускорения часто запрашиваемых данных (расписание, профили пациентов).

**Использование:**
- **Клинический домен** - кэширование расписания приёмов
- **Аналитический домен** - кэширование часто запрашиваемых отчётов
- **API Gateway** - кэширование ответов API

**Бизнес-сценарии:**
- **Быстрый отклик** - расписание загружается мгновенно
- **Снижение нагрузки на БД** - часто запрашиваемые данные в кэше
- **Масштабирование** - снижение нагрузки при пиковых обращениях

**Влияние на бизнес:**
- Время отклика для расписания: секунды → миллисекунды
- Снижение нагрузки на PostgreSQL на 40-60%
