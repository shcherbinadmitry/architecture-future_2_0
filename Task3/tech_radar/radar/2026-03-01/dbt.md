## dbt (data build tool)

**Статус:** Активно внедряем

**Назначение:** Инструмент трансформации данных (T в ELT). Позволяет описывать трансформации как SQL-модели с тестированием и документацией.

**Использование:**
- **Все домены** - создание Data Products (трансформация данных для аналитики)
- **Аналитический домен** - агрегация и подготовка данных в Lakehouse
- **Data Quality** - встроенные тесты качества данных

**Бизнес-сценарии:**
- **Качество данных** - автоматические тесты при каждой трансформации
- **Документация** - автогенерация документации по моделям данных
- **Версионирование** - трансформации в Git, code review
- **Снижение зависимости от DWH** - логика трансформаций в коде, а не в хранимых процедурах

**Влияние на бизнес:**
- Миграция бизнес-логики из DWH в управляемый код
- Снижение ошибок в данных (автоматические тесты)
- Ускорение разработки новых отчётов
